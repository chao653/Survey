# Figma 操作日志（Survey）

> Agent 在 Figma 完成操作后的记录区。走查轮次产物（报告 / 修改清单 / 截图）归 `走查/`，不放这里。

## 文件组织

- 按**类型**组织，一个类型一个文件，例如：
  - `需求卡片和标题.md`：需求说明卡、节点标题卡的增改。
  - `节点N_<主题>.md`：某个功能节点的绘制与修改（如 `节点1_问卷列表.md`）。
  - `业务组件.md`：项目自建业务组件母版的新建 / 调整 / 删除。
- 新类型出现时新建对应文件，文件名用中文语义名，不用日期做文件名。

## 追加规则

- 同一类型的后续操作（含用户在会话外手工修改的补记）在对应文件**末尾**按日期追加一节，只增不覆盖：

```
## YYYY-MM-DD · 一句话摘要

- 任务来源：用户指令 / Linear 工单号 / 走查修改清单 RN-xx
- 涉及节点：`<node_id>`（Figma 链接）
- 操作摘要：做了什么、用了哪些组件 / token
- 结果状态：已完成 / 部分完成（缺口说明）/ 待用户确认
```

## 截图证据

- 归 `参考截图/`，命名 `YYYY-MM-DD-<说明>.png`。
- 日志里引用截图用相对路径。
