## B. 规范合规

| 检查项 | 依据 | 通过标准 |
| --- | --- | --- |
| token 绑定 | `设计执行/规范/design.md` + `figma-preferences.md` | 颜色 / 圆角 / 间距 / 阴影 / 文本样式全部绑库变量或样式；无裸值；容器无未处理的默认白 `#FFFFFF` |
| auto layout | `figma-layer-naming.md` | 所有容器用 auto layout，不用绝对定位堆叠；间距用 `spacing` token |
| 命名 | `figma-layer-naming.md` + `需求说明与节点卡片规范.md` §4.4 | 无 `Frame 1` / `Copy` 等无语义名；标题卡用 `{Title} Header` |
| 基础组件 | `components.md` + `figma-preferences.md` | 用 `ShadCN-Default` 实例，不 detach，不自建重复组件 |
| 图标 | `icons.md` + `figma-preferences.md` | Phosphor SVG 组件实例；无键盘字符冒充图标 |
| UI 文案大小写 | `写作规范.md` | 按组件映射表；无 ALL CAPS、无全小写；同页同角色风格一致 |
| 字重 | `design.md` 文本样式 | 用 `text/{scale}/{weight}` 样式，不手改字重 |
| 卡片 | `需求说明与节点卡片规范.md` §6 | 需求说明卡与节点卡按验收清单逐项过 |
| 页面编排 | `命名规范.md` | 页面顺序 / Section 结构 / 废稿归档按标准 |

## 轮次产物约定

- 每轮产出两份文件，成对存放在 `走查/`：
  - `RN_报告.md`：本轮结论（A 轨 + B 轨结果、总体判断、需用户确认项）。
  - `RN_修改清单.md`：逐条问题，表头 `| # | 问题 | 位置（node_id + 链接）| 依据 | 状态 | 复核备注 |`，状态取值 **待改 / 已改 / 搁置**。
- 修改完成后在**同一份修改清单**里复核勾销（状态改「已改」+ 复核备注），不另开新文件。
- 截图证据放 `走查/截图/`，命名 `RN-<问题#>-<说明>.png`，与报告成对。
- 走查产物不放进 `设计执行/日志/`。
