# Linear 工单流程（Survey）

## 读任务

- 一律用 Linear MCP 读工单（标题、描述、评论、附件、状态）；**不退化成网页抓取**。
- MCP 掉线或未授权时，提示用户重连后再继续，不猜工单内容。

## 处理

- 处理前先读 `../AGENTS.md` 的任务路由表，按任务类型读对应必读文件。
- 工单里的业务规则若与 `需求文档/01_产品规则.md` 冲突，先请用户确认，再动手。

## 处理完

- 自动产出**评论草稿**（放在回复里，不代发）：
  - 改动范围：涉及哪些节点 / 模块。
  - 改动内容：一句话一条。
  - 链接：Figma 节点链接、相关日志或走查文件路径。
  - 结尾：`cc @某人`（待填：默认 cc 谁）。
- 用户手动回评；agent **不代发评论、不改工单状态**，除非用户明确要求。
- 每处理一单在 `History.md` 记一行。
